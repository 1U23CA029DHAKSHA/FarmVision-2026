Overview:

FarmVision 2026 is an agriculture data analytics project developed using Microsoft Excel and MySQL to transform structured farm data into meaningful insights.

The project focuses on analysing cultivation expenses, production, yield, revenue, profit, and Return on Investment (ROI) across different crops.
